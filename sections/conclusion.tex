\section{Conclusion}

Across both datasets, model performance was dependent on the underlying data quality. For Dataset 1, heavy noise and class overlap prevented meaningful learning, with both Logistic Regression and kNN performing just marginally better than a trivial classifier. In contrast, Dataset 2 exhibited clear separability, allowing both models to achieve near-perfect accuracy and AUC. These results highlight that data structure and feature quality, rather than model complexity, primarily determine classification success.
